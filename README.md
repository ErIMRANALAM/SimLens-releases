# SimLens releases

**SimLens** gives the iOS Simulator a camera: your Mac's webcam, a video, an image, a barcode or your screen — so you can test any camera feature without a device or code changes.

## Download

Get the latest **SimLens-x.y.z.dmg** from [Releases](https://github.com/ErIMRANALAM/SimLens-releases/releases/latest), open it and drag SimLens to Applications. Requires macOS 14 or later and Xcode 15 or later.

SimLens is signed with Developer ID and notarized by Apple. Installed copies update themselves (Settings › Updates); every update is signed and verified before it installs.
